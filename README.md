# 街霸6 代打上分 / 教学 / 对练陪玩 报价下单网站

一个纯静态网页：顾客自己选段位、角色、模式，网页自动报价，下单后显示客服 QQ 和收款码。

## 线上地址

**https://dawnighting.github.io/sf6/** （手机、电脑浏览器直接打开即可）

修改文件后，本地测试没问题再 `git push origin main`，GitHub Pages 会自动更新（约 1 分钟内生效）。

## 一、怎么打开

- 直接双击 `index.html` 就能用（无需安装任何东西）；
- 也可以在项目目录运行本地服务器：`python -m http.server 8000`，然后浏览器打开 `http://localhost:8000`。

## 二、三个服务板块

1. **代打上分**：选当前分数（段位+星数，大师选 M 分）与目标分数，自动生成价格；
2. **游戏教学**：选教学类型、时长、角色、模式，按小时报价；
3. **对练陪玩**：选时长、角色、模式，按小时报价。

每个板块点“确认下单”后都会显示订单信息、客服 QQ（2748093282）和收款码位置。

## 三、代打上分的业务规则（已按你的要求实现）

- 段位从低到高：未定级（New Challenger）→ 新手 Rookie → 铁 Iron → 青铜 Bronze → 白银 Silver → 黄金 Gold → 白金 Platinum → 钻石 Diamond → 大师 Master。
- 当前段位下拉顺序：未定级、大师、钻石、铂金、黄金、白银、青铜、铁、新手（你原来的列表里漏了“青铜”，但价格表里有青铜1~5，所以补上了）。
- 目标段位下拉：大师 ~ 铁（不含未定级和新手）。
- 当前分数为未定级时，目标段位只显示钻石和大师；到钻石任意星固定 22 元。
- 大师选 M 分（0~2400），其他段位选 1~5 星。
- 切到大师但 M 分没填：不弹窗，在对应分数框下面显示红字“请填写M分”。
- 目标分数不大于当前分数：不弹窗，在目标分数框下面显示红字“目标分数需大于当前分数”。
- 当前不是大师、目标选大师且 M 分未填 → 默认打到 M1500，不弹窗。
- 当前和目标都是大师 → 两个 M 分都必须填，否则对应分数框下显示红字。
- 选了 DJ / 达尔西姆 / 金柏莉 / 春丽 / 布兰卡 / 阿鬼 / 拉希德 + 现代模式 → 弹窗“抱歉，这些角色只接经典模式（DJ 达尔西姆 金柏莉 春丽 布兰卡 阿鬼 拉希德）”并停止报价。
- 目标 M 分超过 1800 → 弹窗“分数过高请加我qq：2748093282私聊”（价格仍会显示）。
- 目标分数区有“赛季末保传奇拿传奇标”按钮：选中后显示价格区间 1000~1100 元，并提示“具体价格建议联系客服qq2748093282”，与当前分数无关。
- 上分界面选“现代”操作模式：最终价格 × 1.5（传奇固定价不参与）。
- 教学界面选“现代”：角色下拉只保留“杰米”，其余角色移除。
- 对练陪玩界面：可按操作模式、角色、目标段位筛选陪玩（资料在 `js/config.js` 的 `sparPlayers`，先放了样例 cq：拉希德 M2000 / 亚思敏 M1800）。
- 默认：当前=未定级，目标=大师 M1500，操作模式=经典。

## 四、价格是怎么算的（重要，请确认）

你的价格表我按“**从该起点段位打到大师 M1500 的整单价格**”来理解：

> 报价 = 当前段位价格 − 目标段位价格（目标为大师 M1500 时价格为 0）

例：

- 未定级 → 大师 M1500：**25 元 / 连胜 12 场**（未定级上大师基础价）；
- 未定级 → 钻石（任意星）：**22 元**；
- 新手5 → 钻石5：90 − 25 = **65 元**（45 − 10 = 35 场）；
- 未定级 → 大师 M1650：25 + 100×0.6 + 50×0.8 = **125 元**。

连胜场数：大师 M 分部分每 8 分折算 1 场连胜，向上取整。例：未定级 → 大师 M1600 = 12 + 100/8 ≈ **25 连胜**。

大师 M 分按分段计价（元/分）：

| M 分区间 | 单价 |
| --- | --- |
| 1500 以下 | 0.4 元/分 |
| 1500~1600 | 0.6 元/分 |
| 1600~1700 | 0.8 元/分 |
| 1700~1800 | 1.0 元/分 |
| 1800~2400 | 1.3 元/分 |

当前和目标都是大师时，按两个 M 分之间的区间差价计算（如 M800 → M2000 = 700×0.4 + 100×0.6 + 100×0.8 + 100×1 + 200×1.3 = 780 元）。

分段单价在 `js/config.js` 的 `masterMRate` 里可改；目标 M 分超过 1800 的弹窗文案在 `masterTooHighPopup`。

几个说明：

- 未定级上大师基础价 25 元、连胜 12 场（`js/config.js` 价格表里的 `newchallenger` 行）；
- 目标 M 分 ≤ 1500 时按基础价算（不额外减价）；
- 相邻段位价格一样时会出现 0 元（比如新手1→新手2），这是表格本身的特性，如需最低价可以在 `js/config.js` 里加；
- 教学默认 60 元/小时、对练默认 40 元/小时，`js/config.js` 里可改；
- **如果你说的价格算法不是这个（比如是每一小段价格相加），告诉我实际算法，我马上改。**

## 五、放入微信 / 支付宝收款码

1. 把微信收款码图片命名为 `wechat-qr.png`、支付宝收款码命名为 `alipay-qr.png`，放进 `images` 文件夹；
2. 打开 `js/config.js`，把 `wechatQr`、`alipayQr` 改为：

   ```js
   wechatQr: "images/wechat-qr.png",
   alipayQr: "images/alipay-qr.png",
   ```

3. 保存并刷新页面，下单后即可显示收款码。

## 六、修改价格 / 角色 / 联系方式

- 价格、QQ、收款码、单价、现代加价倍数、教学现代限定角色：全部在 `js/config.js` 顶部；
- 角色名单：在 `js/app.js` 的 `CHARACTER_GROUPS`；
- 新增 DLC 角色时，只要在对应分组里加一个 `{ v: "角色名", l: "角色名" }` 即可。
